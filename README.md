# BOT FT ABCD — versão nova

## Variáveis

Crie um arquivo `.env` com:

```env
BOT_TOKEN=SEU_TOKEN
APPLICATION_ID=SEU_APPLICATION_ID_NUMERICO
```

Não use `CLIENT_ID`.

## Instalação

```powershell
npm.cmd install
npm.cmd run deploy
npm.cmd start
```

## Comandos

- `/postar-hierarquia`
- `/promover`
- `/rebaixar`
- `/setar`
- `/exonerar`
- `/painel-set`

## Discord Developer Portal

Ative:

- Server Members Intent

## Permissões do bot

- Gerenciar cargos
- Ver canais
- Enviar mensagens
- Ler histórico de mensagens

O cargo do bot deve ficar acima de todas as patentes.
